公式与使用说明

CKD-EPI eGFRcr 使用 2009 年公式；eGFRcys 与 eGFRcr-cys 使用 2012 年公式，均不使用 Black race 系数。EKFC eGFRcr 使用 2021 年公式，并采用中国成人肌酐 Q 值：男性 0.84 mg/dL、女性 0.61 mg/dL。请确保血清肌酐测量标准化并尽可能使用 IFCC 可溯源的胱抑素 C 结果。

参考曲线来自本研究提供的年龄和性别特异性分位数表（45–85 岁）；参考分位数按上传的 v2 表逐岁绘制。默认显示 P7.5、P10、P25、P50、P75、P90，其中 P7.5 为棕色虚线。该分位数是描述性参考分布，不等同于经验证的个体预后风险百分比。

声明：本工具仅供科研、教学及辅助理解，不能替代临床判断。肾功能评估、CKD 诊断与风险评估应结合 UACR、eGFR 持续时间、临床背景及相关指南。
