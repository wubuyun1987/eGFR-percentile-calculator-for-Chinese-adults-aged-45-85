年龄、性别特异性 eGFR 分位数计算器

输入性别、年龄、血肌酐和胱抑素 C 后，网页将使用 CKD-EPI 2009 肌酐公式、CKD-EPI 2012 胱抑素 C 公式和 CKD-EPI 2012 肌酐-胱抑素 C 联合公式计算 eGFR，并判断其处于 P10、P25、P50、P75、P90 的哪个区间。

输入信息

当前分位数数据覆盖 45–85 岁。肌酐公式默认不使用 Black race coefficient。

计算结果

公式：CKD-EPI 2009 creatinine；CKD-EPI 2012 cystatin C；CKD-EPI 2012 creatinine-cystatin C。单位：mL/min/1.73 m²。
